# Vermieterordner

Website für vermieterordner.de, gebaut aus der Solovorlagen-Vorlage (biz-template). Bis zum Livegang liegt in docs/ nur eine Platzhalterseite (noindex); Workflows liegen in .github/workflows-bis-launch und werden zum Launch nach .github/workflows verschoben.

Bauen: `python3 src/gen_site.py`, `python3 src/qa.py`. Anleitung: README-vorlage.md.
